# Frida-in-the-Prison-Lab
A simple 2D platformer game I'm creating in Pico-8, following one of the MC's in my 5-book Sci-Fi LitRPG series "Overtaken Online" (published 2021-2024). In this game, we follow Frida in her first days in the Daemonorg Prison-Lab, before her first meeting with Darius Hunter (which takes place in the series' companion novella "Impending Doom").
